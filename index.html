01 /創作起點

為什麼
做這個網站？

在接觸數位創作與音樂製作的過程中，我逐漸發現，創作不只是完成作品，更是一種能夠表達個人風格與想法的方式。如果能將聲音、視覺與互動整合在同一個平台中，是否能創造出更完整的體驗？

因此，我決定嘗試製作一個具有個人風格的互動式作品集網站。這個網站不只是作品展示平台，更是一個融合視覺設計、互動效果與創作理念的數位平台。我希望使用者在體驗的同時，不只「觀看作品」，還能感受到作品背後的氛圍、情緒與創作脈絡。

在實作過程中，我從版面設計、動畫安排、色彩配置，到音樂播放器與互動功能的整合，都不斷進行測試與調整，並透過查找資料解決程式與設計上的問題。這讓我更加理解，設計不只是畫面的美感，而是如何建立完整的使用者體驗。

01

課程啟發

在課堂學習中，我接觸到許多與設計相關的領域，平時也會手繪塗鴉，也曾著手製作過服飾的設計，所以我想延伸課堂所學，用想法實踐出完整作品

02

工具探索

從 Figma 到 Webflow，從 AI 協作到 GitHub ，逐步理解HTML、CSS 與 JavaScript 的基本運作邏輯，並透過實際操作將想法轉化爲成果。

03

作品集的意義

對我而言，這不只是成果展示，而是一個融合個人興趣與個人風格的能力整合 。
